# Project Vision

## Problem

Teachers in rural India face challenges:
- **Multi-grade classrooms**: One teacher teaches multiple grades simultaneously
- **Limited internet**: Most schools have poor or no connectivity
- **High workload**: Teachers spend hours creating worksheets and lesson plans
- **No AI training**: Teachers aren't trained to use AI tools effectively
- **Limited resources**: Educational games and interactive materials are expensive

## Solution

Sahayak is an **offline-first AI teaching assistant** that works without internet and improves with online connectivity.

## Core Principles

1. **Offline First** - Everything works without internet. Online is an enhancement only.
2. **Prompt-Free** - Teachers never write prompts. The app understands what they need.
3. **Education-Specific** - Built for classrooms, not generic AI.
4. **One-Click** - Upload → Select options → Download.

## Impact Target

- 50+ teachers using the platform within 3 months
- 1000+ worksheets generated per month
- Zero dependency on internet connectivity

## Success Metrics

- Teachers can generate a worksheet in <2 minutes
- Offline mode works reliably
- Generated content is educationally sound
- Teachers want to use it every day
