# Contributing to Sahayak

Thank you for wanting to contribute!

## How to Contribute

1. **Pick an issue** from [GitHub Issues](../../issues)
2. **Comment** on the issue: "I'll work on this"
3. **Create a branch**:
```bash
   git checkout -b feature/your-feature-name
```
4. **Make your changes**
5. **Test locally**
6. **Commit with semantic message**:
```bash
   git commit -m "feat: your description"
```
7. **Push and create PR**:
```bash
   git push origin feature/your-feature-name
```
8. **Code review** - Team lead will review
9. **Merge** to develop, then main

## Code Quality

- Write clean, readable code
- Add comments for complex logic
- Test before committing
- Follow existing code style

## Commit Message Format

feat(area): add new feature
fix(area): fix bug
docs(area): update docs
refactor(area): reorganize code
test(area): add tests
chore: build/setup changes


Examples:
```bash
git commit -m "feat(worksheet): add image upload"
git commit -m "fix(settings): remove console errors"
git commit -m "docs: update setup guide"
```

## Branch Naming

feature/short-description
bugfix/issue-name
docs/what-you-updated


## Pull Request

Your PR should:
- Have a clear description
- Reference the issue: "Closes #123"
- Pass all tests
- Be reviewed by team lead

## Questions?

Ask in the PR or open an issue.

Happy coding! 🚀
